ИНФА ОТ ЯНДЕКСА
ПУНКТ 1
Для извлечения текста из PDF на Python не используются нейросети, но существуют библиотеки, которые позволяют работать с PDF-файлами с помощью оптического распознавания символов (OCR) или обработки естественного языка (NLP). Эти методы не требуют использования нейросетей, но позволяют извлекать текст из PDF-документов, преобразовывать его в редактируемый формат и анализировать с помощью NLP. 

С использованием OCR (Optical Character Recognition)
PyTesseract — библиотека для OCR, которая позволяет преобразовывать PDF-файлы в текст. Алгоритмы OCR анализируют формы и узоры символов на изображении, идентифицируют текст. 
EasyOCR — библиотека OCR с открытым исходным кодом, разработанная Jaided AI. Поддерживает более 80 языков, включая латиницу, китайский, арабский и другие. С предобученными моделями глубокого обучения может обнаруживать и распознавать текст в различных шрифтах, рукописных стилях и сложных фонах. 

С использованием NLP (Natural Language Processing)
PyPDF2 — библиотека для работы с PDF-файлами, которая позволяет извлекать текст с страниц. Для этого нужно получить страницу документа с помощью функции getPage() и вызвать функцию extractText().
NLTK — платформа для обработки текста, которая содержит библиотеки для токенизации, анализа, классификации и других задач. С её помощью можно извлекать текст из PDF-файла, например, извлекать имена с определённой страницы.

ПУНКТ 2
Для создания Excel-файла и наполнения его информацией с помощью Python можно использовать библиотеки openpyxl или Spire.XLS. Они позволяют работать с файлами Excel (.xlsx) напрямую из Python, не запуская Excel. 

С библиотекой openpyxl
Создание нового Excel-файла с помощью openpyxl:
Создать рабочую книгу (Workbook).
Добавить листы.
Записать данные в ячейки, используя объект листа и координаты ячейки. Например: sheet["A1"] = "Текст", sheet["B1"] = 123.
Сохранить изменения с помощью метода save().
 
Некоторые возможности:
Изменение ширины столбцов и высоты строк.
Настройка стилей ячеек (жирный шрифт, цвет текста, выравнивание) с помощью модуля openpyxl.styles.
 
С библиотекой Spire.XLS
Создание документа Excel с нуля с помощью Spire.XLS for Python:
Создать объект Workbook.
Добавить рабочий лист с помощью метода Workbook.Worksheets.Add().
Записать данные в определённые ячейки с помощью свойства Worksheet.Range.Text.
Сохранить рабочую книгу в документ Excel с помощью метода Workbook.SaveToFile().
 
Некоторые особенности:
Поддержка форматов Excel 97–2003 (.xls) и новых форматов Excel 2007, 2010, 2013, 2016 и 2019 (.xlsx, .xlsb, .xlsm).
