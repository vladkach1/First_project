# Telegram-бот для подготовки коммерческих предложений

Асинхронный Telegram-бот для автоматизации первичной обработки спецификаций оборудования: извлекает позиции из PDF, ищет товары и цены на сайтах поставщиков и формирует Excel-отчёт.

> Учебный/портфолио-проект. Результаты автоматического распознавания и веб-поиска следует проверять перед использованием в коммерческих расчётах.

## Возможности

- Приём файлов через Telegram и проверка ограничений на входные документы.
- Извлечение текста и данных из PDF с помощью `pdfplumber` и PyMuPDF.
- OCR-обработка страниц и отдельных областей документов.
- Асинхронный поиск номенклатуры на сайтах поставщиков с помощью Playwright и Beautiful Soup.
- Ограничение параллельной обработки страниц браузера.
- Формирование и обработка таблиц Excel с помощью pandas и openpyxl.
- Кэширование результатов поиска для повторных запросов.
- Логирование и централизованная обработка ошибок.

## Технологии

**Python**, **asyncio**, **python-telegram-bot**, **Playwright**, **Beautiful Soup**, **pdfplumber**, **PyMuPDF**, **RapidOCR**, **Pillow**, **NumPy**, **pandas**, **openpyxl**, **OpenAI-compatible API**, **python-dotenv**.

## Как работает обработка

1. Пользователь отправляет спецификацию боту.
2. Бот извлекает текст из PDF; для сканированных страниц применяется OCR/мультимодальная обработка в зависимости от используемого пути.
3. Из документа формируется список позиций оборудования.
4. Бот ищет подходящие предложения на настроенных сайтах поставщиков.
5. Найденные сведения собираются в Excel-отчёт; позиции, которые не удалось надёжно сопоставить, требуют ручной проверки.

Сайты поставщиков, тайм-ауты и параметры параллельной обработки задаются в `config.py`.

## Требования

- Python 3.10 или новее.
- Доступ к Telegram Bot API.
- API-ключи тех AI-провайдеров, которые используются в текущей конфигурации.
- Интернет-доступ к сайтам поставщиков.

## Установка и запуск

Команды приведены для локального запуска из корневой папки проекта.

### 1. Создать виртуальное окружение

**Windows (PowerShell):**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
playwright install chromium
```

Если установленный Playwright сообщает об отсутствующих системных библиотеках браузера, установите зависимости Chromium для своей операционной системы.

### 3. Настроить переменные окружения

Скопируйте шаблон и заполните его собственными ключами:

**Windows (PowerShell):**

```powershell
Copy-Item .env.example .env
```

**Linux / macOS:**

```bash
cp .env.example .env
```

Откройте локальный `.env` и укажите значения:

- `BOT_TOKEN` — токен Telegram-бота.
- `GEMINI_API_KEY` — ключ Gemini, если соответствующий путь обработки включён в коде.
- `OPENROUTER_API_KEY` — ключ OpenRouter, если используется этот провайдер.

Не публикуйте файл `.env`, не вставляйте реальные ключи в исходный код и отзывайте ключи, если они случайно попали в репозиторий.

### 4. Запустить бота

```bash
python bot.py
```

Для Windows в репозитории также предусмотрен вспомогательный файл `run_bot.bat`; при проблемах ориентируйтесь на сообщения терминала и шаги установки выше.

## Структура проекта

```text

├── error_handler.py       # Обработка ошибок

├── run_bot.bat            # Запуск в Windows

```

## Ограничения и дальнейшее развитие

- Структура и разметка страниц сайтов поставщиков могут меняться, поэтому парсеры нуждаются в поддержке.
- Автоматическое сопоставление названий не гарантирует идентичность товара; перед закупкой нужно сверять артикул, характеристики, цену и наличие.
- Ответы внешних AI-сервисов могут быть неполными или ошибочными.
- Перспективные улучшения: автоматические тесты, типизация, более подробная валидация извлечённых данных, метрики качества сопоставления и CI.
